## MidiPult Android 1.0.8

### Интерфейс
- Нижнее меню «Панель · Колонки · Меню» больше не участвует в анимации перехода в раздел «Колонки» — анимируется только контент.
- Исправлена анимация появления списка колонок.

### Обновления
- Скачанный APK теперь удаляется после успешной установки обновления, чтобы не занимать место на телефоне.
- Если установка отменена, APK остаётся для повторной попытки.
- Очистка выполняется при следующем запуске уже обновлённого приложения.

### Совместимость
- Обновление устанавливается поверх 1.0.7 с сохранением колонок и настроек.
