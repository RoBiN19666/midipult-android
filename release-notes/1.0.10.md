# MidiPult Android 1.0.10

- Полноценный системный плеер: уведомление в шторке и на экране блокировки с
  обложкой, названием, исполнителем и кнопками «назад / пауза / вперёд».
- Аппаратные кнопки громкости Android показывают системную шкалу
  «Громкость мультимедиа», но меняют только громкость колонки. Громкость
  самого телефона не трогается.
- Управление из шторки работает и при свёрнутом приложении: команды уходят
  напрямую в API станции, если WebView уже нет.
- Запрос разрешения на уведомления на Android 13+.
