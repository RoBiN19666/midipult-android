# MidiPult Android 1.1.1

- **Актуальная версия панели в разделе «Колонки».** При открытии списка
  приложение теперь запрашивает `/version.json` у каждой сохранённой колонки,
  обновляет подпись «панель v…» и сохраняет её. Раньше показывалась версия,
  записанная при последнем сканировании.
- **Без чёрных полос сверху и снизу.** Фон окна и системных панелей теперь
  общий градиент приложения, а не сплошной чёрный; навигационная панель
  учитывает системные отступы и не отрезает контент.
- Панель 0.6.1: исправленная проверка токена Сбер Звука, очередь Яндекс
  Музыки без дублей и «Похожие» с треками исполнителя.
