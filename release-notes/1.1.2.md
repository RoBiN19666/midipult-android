# MidiPult Android 1.1.2

- **Подписи кнопок по центру.** У кнопок «Открыть», «Сканировать»,
  «Добавить колонку» и других убран визуальный перекос текста по вертикали.
- **Иконки-кнопки по центру.** Карандаш и корзина в карточке колонки теперь
  стоят ровно по центру, а не выше середины.
- Версия панели в «Колонках» подтягивается из `/version.json` при открытии
  списка, фон без чёрных полос.

Совместимо с панелью MidiPult 0.6.1.
