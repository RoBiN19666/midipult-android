# MidiPult Android 1.1.4

- **Кнопки громкости больше не отбираются у телефона**, когда на нём играет
  другой плеер. Если через Bluetooth звучит VK Музыка (или что-то ещё), MidiPult
  отдаёт громкость системе: аппаратные кнопки меняют громкость телефона, а не
  колонки. Проверка идёт по `AudioManager.isMusicActive()` раз в 3 секунды и
  сразу по флагу `fromPhone` из панели.
- Когда играет станция, всё как раньше: кнопки громкости показывают свою шкалу
  «Громкость мультимедиа» и меняют громкость колонки.

Совместимо с панелью MidiPult 0.6.11.
